02 / The system

Four specialists.
One considered decision.

Each minister owns a defined risk surface. Their findings are combined into a single, legible recommendation — not hidden behind a score alone.

01 / Secrets⌘

VAULT

Finds credentials and sensitive values in proposed arguments before they are passed to tools.

02 / Execution↳

EXECUTOR

Checks risky shell and code-execution patterns where a seemingly ordinary call could cause harm.

03 / Data movement⇢

CHANNEL

Looks for suspicious relationships between sensitive reads and external destinations across a session.

04 / Policy context◎

NAVIGATOR

Uses Invariant Guardrails policies to reason over the current call and the evidence available to it.

03 / Decision language

Make risk clear. Keep the boundary real.

Kavach provides a recommendation, not an execution permission. The real tool boundary must enforce the final result.
